# 接口录制器

一个 Chrome/Edge Manifest V3 扩展：在测试操作期间，自动记录当前标签页发出的 Fetch/XHR 请求及其完整响应，并导出为 JSON 数组。

## 使用

1. 打开 Chrome/Edge 的“扩展程序”页面，启用开发者模式。
2. 选择“加载已解压的扩展程序”，选择本目录。
3. 在目标业务页面打开扩展，点击“开始”；浏览器会显示调试权限提示。
4. 完成测试操作后点击“停止”，再点击“导出 JSON”。

## 导出结构

每条记录具有 `timestamp`、`method`、`url`、`request`（headers/body）和 `response`（状态、headers、body、编码）字段。二进制响应使用 `base64` 标记；文字响应使用 `utf-8` 标记。导出前记录会按时间戳排序。

## 过滤与边界

- 仅录制 CDP 分类为 `Fetch` 与 `XHR` 的请求。
- 自动排除常见静态资源扩展名，以及 URL 中的 health、heartbeat、ping 请求。
- “暂停”会继续连接调试器但不写入完成的请求；“停止”断开调试器且保留已录制数据供导出。
- 页面或浏览器扩展调试器被其他工具占用时，Chrome 可能拒绝附加；关闭冲突的 DevTools/调试扩展后重试。
