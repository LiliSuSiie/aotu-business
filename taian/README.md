# 泰安评议：新手运行指南

适用电脑：当前这台 Windows 电脑。项目位置：`E:\liwenqiu\project\aotu-business`。

如果刚从 GitHub 下载，账号配置不会随仓库提供。先按项目首页的“从 GitHub 下载后首次准备”复制配置模板并安装依赖；已有配置时不要重复复制覆盖。以下绝对路径适用于上述安装位置，换目录后按实际位置调整。

你只需要完成四件事：**检查账号 → 打开终端 → 输入启动命令 → 按序号选择批次和评议员**。程序会自动登录、提交评议、检查结果，最后将该评议员改成“已完成”。不需要手工填写 Token，不需要打开业务网页逐户点击。

**当前是测试评议模式。** 程序把“是否了解”“是否适宜授信”以及该成员的全部评议要素统一填为 true（是／选中）。这是此前已确认的测试规则，不是程序根据客户资料作出的判断。如果要录入真实且不同的评议意见，需要先调整输入规则。

## 第一步：检查登录账号

1. 按键盘上的 **Win + E**，打开文件资源管理器。
2. 点击窗口上方的地址栏，粘贴下面的文件夹路径，按回车：

   ```text
   E:\liwenqiu\project\aotu-business\taian\config
   ```

3. 找到 **review.private.json**，右键选择“打开方式 → 记事本”。也可以直接打开本机账号配置文件。
4. 只修改 `username` 和 `password` 双引号里面的内容。账号已经正确时不必修改。

文件格式如下，**这里是格式示例，不是让你覆盖现有账号**：

```json
{
  "baseUrl": "http://47.98.151.170:8085/xczx/backend",
  "username": "你的登录账号",
  "password": "你的登录密码"
}
```

填写明文账号和密码即可。程序会自动加密，再向服务器登录。不要把密码改成密文，不要增加 Token 字段。服务地址没有变时，保留 `baseUrl` 原值。

保留英文双引号、逗号和大括号，不要换成中文引号。如果密码本身包含英文双引号或反斜杠，在 JSON 中分别写作 `\"` 或 `\\`；一般密码中的 `!` 无需额外处理。完成后按 **Ctrl + S** 保存，文件编码保持 UTF-8。

真实密码只放在这个本地私有配置文件中，不要粘贴到说明文档或发送给其他人。

## 第二步：打开终端

终端就是一个可以输入命令的窗口。

1. 同时按 **Win + R**。
2. 输入 `powershell`，按回车。
3. 出现一个带文字输入位置的窗口，就可以继续了。无需管理员身份。

## 第三步：启动程序，不生成报告

复制下面**完整的一行**，粘贴到 PowerShell，按回车。只复制命令，不要复制代码框的边框或 `powershell` 标题。

```powershell
python "E:\liwenqiu\project\aotu-business\taian\scripts\run_review.py" --no-report
```

这条命令在任意文件夹位置都能运行，不需要先切换目录。

`--no-report` 表示不生成报告和 HTTP 日志，符合目前的使用方式。程序仍会保留续跑台账，用来识别已经保存的户，避免重复提交。

正常情况下，窗口先显示：

```text
正在登录……
登录成功，已获取本次会话。
```

## 第四步：选择评议批次

登录成功后，程序会显示这个账号能够看到的批次。例如：

```text
选择评议批次
1. 报表村居 | code=一串批次编号 | 状态=0 | 类型=1
输入序号或完整 code（q 退出）：
```

输入想处理的批次前面的数字，例如 **1**，按回车。不用复制很长的 code，输入序号即可。

有多个批次时，按名称确认后再选择。每次返回的顺序可能变化，不要固定输入同一个数字。

## 第五步：选择评议员，然后等待完成

接下来显示刚才这个批次里的评议员。例如：

```text
选择本批次评议员
1. bb03 | code=一串编号 | 已完成 | 已办=7 待办=0
2. bb01 | code=一串编号 | 待评议 | 已办=0 待办=7
3. bb02 | code=一串编号 | 待评议 | 已办=0 待办=7
输入序号或完整 code（q 退出）：
```

上面只是展示格式，**以你当次窗口里的姓名、状态和待办数为准**。

想处理 bb01，就输入它在当次列表里的序号，例如 **2**，按回车。

**选择评议员并按回车后，程序会立即开始实际保存，不再问一次“是否确定”。** 每次只处理所选评议员的全部待办，不会自动把其他评议员也做完。

运行期间保持窗口打开。窗口会逐户显示进度；一户可能有多名家庭成员，程序会一起提交并检查。

成功结束时会看到类似内容：

```text
{"complete": true, "householdsVerified": 7, "membersVerified": 10, "writesThisInvocation": 8, "untargetedReviewersUnchanged": true}
运行结束，未生成报告。
```

你主要看这三项：

| 窗口内容 | 含义 |
| --- | --- |
| `complete: true` | 所选评议员任务已完成 |
| `householdsVerified: 7` | 本次任务清单中有 7 户已检查通过 |
| `membersVerified: 10` | 这 7 户共有 10 名成员已检查通过 |

数字只是示例。有历史已完成户时，程序保留历史结果，当前任务统计不把它们重复算作本次新增。只有“登录成功”或某一户进度完成，还不等于整名评议员任务完成。

如果列表里还有其他人员待办，**重新运行第三步的命令，再选择同一批次和下一名评议员**。不需要改代码。

## 我想先看看，不实际提交

使用这条命令：

```powershell
python "E:\liwenqiu\project\aotu-business\taian\scripts\run_review.py" --dry-run --no-report
```

仍然要选择批次和评议员，但只会登录、查询和检查，不保存评议、不修改完成状态。试完后，想真正执行，再使用第三步的正常命令。

## 我想先只处理一户

使用这条命令：

```powershell
python "E:\liwenqiu\project\aotu-business\taian\scripts\run_review.py" --limit 1 --no-report
```

`--limit 1` 表示本次最多新保存一户。还有其他户没做完时，出现 `complete: false` 是正常的。

之后用第三步的正常命令，使用**相同账号，选择相同批次和评议员**，程序会先检查已有结果，再继续剩余户。不要删除台账来“重新开始”。

## 如果我以后需要报告

去掉命令末尾的 `--no-report` 即可：

```powershell
python "E:\liwenqiu\project\aotu-business\taian\scripts\run_review.py"
```

生成位置会显示在窗口中，位于 `E:\liwenqiu\project\aotu-business\taian\reports\interactive` 下。只想完成评议时，继续使用第三步的无报告命令即可。

## 常见问题

| 看到的情况 | 怎么处理 |
| --- | --- |
| `python` 不是命令，或弹出应用商店 | 用下方“本机 Python 完整路径”命令启动，无需立刻重装 Python。 |
| `No module named 'Crypto'` | 缺少加密组件，执行下方安装命令，成功后重新启动。 |
| 提示填写 username／password，或配置格式错误 | 回到第一步检查内容、英文标点和 UTF-8 编码，保存后再运行。不要反复用错误密码登录。 |
| 登录失败 | 检查新账号、密码和服务地址。若该环境额外要求短信验证码，需要有效验证码，程序不能跳过验证。 |
| `URLError` 或连接超时 | 检查网络、所需 VPN 和服务是否可访问。命令由你在本机 PowerShell 执行，无需修改 Codex 设置。 |
| 没有可选批次 | 当前账号没有查到可见批次，先在业务系统核对该账号的权限及批次。 |
| 没有可选评议员 | 该批次可能还没有配置参与人员，先在业务系统配置好后重跑；程序不会代选候选人或自动创建名单。 |
| 评议员已完成、待办为 0 | 无需再做，程序不会重复写入。选择其他有待办的人员。 |
| 类型不支持或批次不可评议 | 当前脚本只启用首轮、要素模式的有效批次，不能强行改状态来执行。 |
| 提示批次已有运行锁 | 先检查是否还有另一个窗口在运行同批次。确认全部退出后仍报错，把提示发给维护人员处理；不要自行删除 state 文件夹。 |
| 回查不一致、状态冲突、结果未知 | 保留窗口提示和台账，请维护人员定位。不要通过删台账或反复提交来跳过检查。 |

**本机 Python 完整路径**（仅当普通 python 命令不可用时使用）：

```powershell
& "E:\Program Files\Sofrtware\Miniconda\python.exe" "E:\liwenqiu\project\aotu-business\taian\scripts\run_review.py" --no-report
```

**安装加密组件**（仅在提示缺少 Crypto 时执行一次）：

```powershell
& "E:\Program Files\Sofrtware\Miniconda\python.exe" -m pip install -r "E:\liwenqiu\project\aotu-business\taian\requirements.txt"
```

**退出与中断：** 还在选择菜单时输入 `q` 并回车，可直接退出。已经开始提交时，如确实需要停止，可按 Ctrl + C；停止不会撤销此前已保存的数据。重新执行时用相同账号、批次和评议员，程序会先回查，再决定是否可以接续。

## 哪些文件可以改

| 文件或文件夹 | 你通常需要做什么 |
| --- | --- |
| `review.private.json`（本机私有配置） | 更换账号时修改用户名和密码 |
| [run_review.py](scripts/run_review.py) | 用上面的命令启动，一般不用编辑 |
| `E:\liwenqiu\project\aotu-business\taian\state` | 自动保存续跑信息，不要删除或修改；包含敏感业务关联值 |
| `E:\liwenqiu\project\aotu-business\taian\reports` | 选择生成报告时查看；不生成报告也可以完成评议 |
| `T.json`（仅本机保留） | 原始录制参考，新版运行不用从这里取账号或 Token |
