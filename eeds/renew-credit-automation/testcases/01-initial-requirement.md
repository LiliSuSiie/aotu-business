# 初始需求：验收与回归用例

除非特别说明，触发“数据跑批”后同时校验 `batch_task_log`、`renew_credit_customer` 和模型桩调用记录。

| ID | 优先级 | 场景与前置 | 执行 | 预期结果 |
| --- | --- | --- | --- | --- |
| RC-I-01 | P0 | 有效合同，到期日为当天，全部关联数据完整，有效白名单，年龄 25 | 运行目标日期数据跑批 | 生成 1 条客户；任务 `finish`；依次调用 M01、M02、M03、M05，续贷场景类型为 `1` |
| RC-I-02 | P0 | 到期日为目标日 +90 天 | 跑批 | 纳入客户并执行模型 |
| RC-I-03 | P0 | 到期日为目标日 +91 天或已到期 | 跑批 | 不生成客户、不调用模型 |
| RC-I-04 | P0 | 状态为 `INEFFECTIVE`、`INVALID`、`CANCELLED` 各一份 | 跑批 | 均不纳入客户 |
| RC-I-05 | P1 | `customerid` 为空、核心客户 ID 为空、`oldlcno` 无法提取进件 ID、进件不存在各一份 | 跑批 | 均不入续授信表；任务继续完成，不能因单条脏数据中断 |
| RC-I-06 | P0 | 进件 `loanType=2` 的历史续授信 | 跑批 | 不入表、不调用模型 |
| RC-I-07 | P0 | 年龄 24、25、64、65 各一份，其他条件有效 | 跑批 | 25/64 进入模型；24 为准入拒绝且允许后续重跑；65 为准入拒绝且标记待确认、不再重跑 |
| RC-I-08 | P0 | 白名单缺失、白名单无效（含无效原因）、白名单有效 | 跑批 | 前两者准入拒绝并保留正确原因；有效者继续模型 |
| RC-I-09 | P0 | 模型桩依次返回通过，含额度和利率 | 跑批 | 客户状态为模型通过，额度/利率写入，客户经理确认状态为待确认；列表可见 |
| RC-I-10 | P0 | M01/M02/M03/M05 分别返回拒绝 | 各跑一次 | 终止后续模型；状态为模型拒绝，拒绝原因可追溯；不可覆盖为模型异常 |
| RC-I-11 | P0 | 任一模型抛异常或超时 | 跑批 | 客户状态为模型异常；任务异常处理、通知和日志完整；无“成功列表”半成品展示 |
| RC-I-12 | P1 | 模型返回审批中 | 跑批 | 状态为模型审批中，且不被误判为通过/拒绝 |
| RC-I-13 | P0 | 同身份证号、同合同号，重复执行同一日期及不同日期跑批 | 跑批两次 | 客户表不重复插入；不得重复调用无须重跑的通过客户 |
| RC-I-14 | P1 | 已通过客户，33 个月内再次跑批；超过 33 个月 | 分别跑批 | 33 个月内不调用模型；超过后可按规则再次进入 |
| RC-I-15 | P0 | 同日同任务已处于 `executing` | 并发触发两个数据跑批 | 仅一个实例执行，另一个明确失败；不会生成重复任务日志/客户 |
| RC-I-16 | P0 | 在第 N 条客户模型调用时制造异常 | 跑批后重跑 | 任务记录为 `exception`；成功完成后才能在列表展示；重跑不造成已完成数据重复 |
| RC-I-17 | P1 | 模型通过且客户归属经理 A | A 查询列表并确认 | 仅展示授权数据；确认后状态改变，重复确认返回业务错误或幂等结果 |
| RC-I-18 | P0 | 同一客户归属经理 A，经理 B 登录 | B 查询并调用确认 | 列表不暴露无权数据；确认被拒绝，记录不改变 |
| RC-I-19 | P1 | 文件开关未配置、为 0、为 1；准备两个批次通过且已确认客户 | 运行文件任务 | 前两者不生成/上传；开关为 1 时仅生成目标批次、目标到期范围客户，文件记录数与查询一致 |
| RC-I-20 | P1 | SFTP 测试目录不可写或上传失败 | 运行文件任务 | 任务为 `exception`、产生通知；不得标记 `finish`；本地临时文件清理符合约定 |
| RC-I-21 | P0 | 已创建续授信进件/合同、未申请、拒绝、签约各一条 | 运行数据更新任务 | `renew_result` 分别更新为未申请、失败、待签约、已签约；只能关联本条续授信客户，不能按身份证串单 |
| RC-I-22 | P1 | 两个历史批次 | 指定其中一个 `batchDate` 运行数据更新/文件任务 | 仅目标批次的数据、文件和状态发生变化，历史批次不变 |

## 初始版检查 SQL（按测试环境字段名复核后执行）

```sql
-- 同证件号+合同号只能有一条续授信客户记录
SELECT id_number, contract_no, COUNT(*)
FROM renew_credit_customer
WHERE del_flag = '0'
GROUP BY id_number, contract_no
HAVING COUNT(*) > 1;

-- 已完成任务不应残留 executing
SELECT * FROM batch_task_log
WHERE task_type IN ('doData', 'doFile', 'updateData')
  AND status = 'executing';
```
