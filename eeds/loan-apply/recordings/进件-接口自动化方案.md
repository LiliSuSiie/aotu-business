# 进件录制接口自动化方案

## 录制事实

`eeds/进件.json` 共录到 26 个请求，均返回 HTTP 200。业务请求由网关 `POST /backend/comm/gateway/forward` 转发，真实业务路径位于请求体的 `requestUrl`，内部方法位于 `requestMode`。

| 阶段 | 录制到的逻辑接口 | 关键关联与断言 |
| --- | --- | --- |
| 产品初始化 | `GET /comm/moblie/loan/code` | 输入 `prdCode`；响应 `data.reqCode` 是全链路主关联值 |
| 字典加载 | `GET /comm/sys/dict/items` | 校验 `education,nation,sex,hyzk,ssq` 等字典非空 |
| 身份材料 | 文件上传、`files/list/v2/`、`loan/ocr` | 上传文件标识 → OCR 的 `code`；`reqCode` → 文件列表 `bizCode` |
| 协议授权 | `tpl/authSample`、`sign/seal/opration/save` | 同一 `reqCode` 为 `bizCode`；录制包含授权类型 13、2、1、7 与对应签章节点 |
| 手机核验 | `customer/telephone`、`customer/verifycode` | 手机号加密值、`reqCode`、短信验证码；验证码绝不写入仓库 |
| 客户保存 | `customer/save` | 客户信息、证件照片、`code=reqCode`；成功后才能进入活体核验 |
| 活体与提交 | `live/check/url`、`live/check/result`、`micro/access` | 以同一 `bizCode/reqCode` 查询活体和最终提交结果 |

## 自动化方案

采用“AI 根据录制生成脚本，k6 确定性执行”的分层方式：

1. **只读冒烟（默认）**：字典接口与网关封装验证；不会创建进件、发短信、上传文件或调用活体。
2. **准备阶段**：调用产品取码，并校验 `reqCode`；该动作可能产生服务端上下文，只在隔离测试环境运行。
3. **完整进件回归（显式启用）**：按录制顺序运行 OCR、授权、短信、保存、活体、提交；由模型/短信/活体服务桩提供确定结果。
4. **上传独立处理**：本次 JSON 没有保留 `multipart/form-data` 的请求体。脚本已按服务端控制器签名补齐真实 `POST /comm/files/upload/v1` 调用：以本次 `reqCode` 为 `bizCode` 上传前、后身份证图，再按该 `reqCode` 查询文件和执行 OCR。

## 数据与安全边界

- 录制文件含个人信息、身份证图片和加密字段。脚本不会复制这些内容；姓名、证件号、手机号、Token 及对应密文均为本机私有运行变量。测试环境验证码挡板下，脚本默认使用 `123456`，也允许任意六位数字。
- 运行完整流程必须使用专用测试客户、测试手机号、模型/SMS/活体桩和可清理的测试企业。
- `MODE=full` 会写入数据、发送验证码并可能调用外部服务，默认禁止运行；需要显式传参启用。

## 覆盖与断言

| 级别 | 覆盖 | 关键断言 |
| --- | --- | --- |
| P0 | 网关协议、`reqCode` 传递、OCR 前后面、四份授权、客户保存、最终提交 | HTTP 200 且业务 `code='0'`；响应携带 `reqCode`；所有后续请求使用同一 Code |
| P1 | 字典、文件列表、短信、活体 URL/结果 | 需要的字典/文件存在；短信发送/核验成功；活体结果通过 |
| P1 负向 | 缺失/错误产品码、错误文件 Code、错误验证码、未完成活体即提交、过期 `reqCode` | 业务失败且不创建可提交进件；失败原因可定位 |
| P2 | 网络超时、网关 5xx、OCR/活体桩异常、重复提交 | 保留请求 ID、响应和阶段标签；状态不被错误推进 |

## 执行前待确认项

1. 测试环境的网关地址、认证 Header 名称和是否必须传 `EnterpriseCode`。
2. 前后身份证测试文件必须与所配置的测试客户一致；上传字段名已按当前代码核实为 `bizCode,multipartFile,bizType,enterpriseCode`。
3. 加密字段由何处生成；脚本只接收已获授权的测试环境密文，不实现或绕过加密。
4. OCR、签章和最终进件的测试桩行为及清理方式。短信挡板已知为任意六位数字通过；活体挡板已知可按真实接口路径调用，脚本断言其返回业务结果。
